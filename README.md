### 💊 Handi — 독거노인을 위한 AI 기반 통합 돌봄 플랫폼

> 🏆 공통 프로젝트 우수상(서울 3반 1등)<br>
> `2025.07.07 – 2025.08.18` · 6인 · **간호사 · 보호자 웹 개발, 약품 검색 정확도 개선** (기여도 33%)

독거노인을 돌보는 관리자 · 간호사 · 보호자를 하나의 플랫폼으로 연결하는 AI 통합 케어 솔루션입니다.

**주요 기능**

- 💊 **AI 복약 관리** — AI 비전으로 복약 여부를 실시간 모니터링하고, 자동 알림과 복약 이력 추적 제공
- 🩺 **원격 의료 연계** — WebRTC 기반 의사 · 보호자 화상 면담, 처방전 발급
- 📄 **스마트 문서 관리** — 의료 기록 디지털화, AI 자동 마스킹, 간병일지 자동 생성
- 🤝 **스마트 매칭** — 보호자와 요양보호사 AI 매칭 및 일정 자동 조율

**담당**

- 💊 **약품 검색 정확도 개선** — 약봉투 사진에서 AI가 인식한 약품명으로 약을 찾을 때 이름은 같고 용량이 다른 약품이 먼저 검색되는 오류를 발견, 약품명과 용량의 반영 비율을 조정해 **첫 검색 결과 정확도 72.98% → 99.06%**
- Layered Architecture(application · domain · infrastructure)와 Atomic Design 기반 컴포넌트 구조 설계
- React Router v7로 역할별 라우트 그룹화, 가드 로직으로 권한 없는 접근 차단
- TanStack Query 캐싱 · 동기화와 Axios 인터셉터 기반 인증 · 토큰 갱신으로 렌더링 지연과 중복 에러 처리 감소

**Tech** `React` `TypeScript` `TanStack Query` `Zustand` `Axios` `React Router v7` `Ant Design 5` `Tailwind CSS v4`
